# Login Form with React State Management by VASU WATTS
This project demonstrates the development of a simple yet functional login form built with React. It showcases the use of the useState hook for efficient local state management within functional components. The form includes dedicated input fields for both username and password, each dynamically synchronized with component state to reflect user input in real time.

The primary objective of this implementation is to illustrate how React’s state management capabilities can be leveraged to handle controlled components effectively. When the user interacts with the input fields, the internal state is updated instantaneously. Upon submission, the entered credentials—comprising the username and password—are programmatically logged to the console, exemplifying fundamental event handling and state tracking in React.

The project serves as a foundational exercise in understanding React’s unidirectional data flow, event-driven architecture, and form-handling mechanisms. It lays the groundwork for integrating more advanced features such as form validation, authentication, and API connectivity in subsequent iterations.
